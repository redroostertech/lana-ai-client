# Lana AI + Tailscale Setup - Quick Guide

## You've Been Invited!

You've been invited to access the Lana AI server securely via Tailscale VPN.

---

## Setup Instructions (5 minutes)

### Step 1: Install Tailscale

**Before installing Lana AI**, install Tailscale on your device:

**iOS/iPad:**
- Open App Store → Search "Tailscale" → Install
- Open Tailscale → Sign in with your invitation email → Tap "Connect"

**Android:**
- Open Google Play → Search "Tailscale" → Install
- Open Tailscale → Sign in with your invitation email → Tap "Connect"

**macOS:**
- Visit: https://tailscale.com/download/mac
- Download and install → Sign in → Click "Connect"

**Windows:**
- Visit: https://tailscale.com/download/windows
- Download and install → Sign in → Click "Connect"

---

### Step 2: Install Lana AI

**After Tailscale is connected:**

1. **Download the installer** for the appropriate device type
2. **Ensure Lana AI is fully closed** (quit the app completely)
3. **Run the installer** and follow the prompts
4. **Relaunch Lana AI** and sign in
5. The app will automatically discover the server via Tailscale

---

## That's It!

Lana AI will now connect securely to the server through Tailscale. No additional configuration needed!

### Need Help?

**Connection Issues?**
- Make sure Tailscale shows "Connected" (green icon)
- Try closing and reopening Lana AI
- Check that you're signed into Tailscale with the correct email

## What is Tailscale?

Tailscale creates a secure, private network between your device and the Lana AI server. Think of it as a secure tunnel that lets you access the server from anywhere - home, office, coffee shop, or on cellular data.

**Security Features:**
- ✅ End-to-end encrypted
- ✅ Works from anywhere
- ✅ No complex setup
- ✅ Automatic HTTPS certificates
