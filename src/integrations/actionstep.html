ActionStep Not Configured

The ActionStep integration requires server configuration.

Administrator Setup Required

Add the following to your .env file:

# ActionStep Integration
ACTIONSTEP_IMPORT_DIR=/path/to/actionstep/export
ACTIONSTEP_SYNC_FREQUENCY=daily

The import directory should contain:

  • data/ - CSV files (actions.csv, participants.csv, etc.)
  • documents/ - Document files for RAG processing
