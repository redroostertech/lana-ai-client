🔧 Troubleshooting

No events showing?
  • Make sure you attached files to your message
  • Check browser console for "[Smart Routing]" logs
  • Verify server is running and connected
  • Hard refresh (Cmd+Shift+R / Ctrl+Shift+R)
Events showing but no UI?
  • Check for JavaScript errors in console
  • Verify reasoning panels exist in chat.html DOM
  • Make sure showReasoning() function is defined
Progress stuck or incomplete?
  • Check server logs for backend errors
  • Verify Document Agent completed successfully
  • Check network tab for SSE connection issues
